# 小梦 2.0 · 云朵工作室落地

## 页面

- 首页：奶杏与柔粉主视觉、可点击打招呼的小梦、整页滚动、会话卡片、下拉同步。
- 导航：手机底部会话/项目/主机入口，桌面固定项目侧栏。
- 项目与主机：统一卡片、主机能力标签与品牌插画，展示真实已同步数据。
- 对话：安静白底、可读正文、折叠执行过程、状态小梦、浮起的奶白输入区。
- 设置：模型与推理配置仍从输入区打开；发送和停止继续共用一个主按钮。
- 新会话：表单支持随键盘滚动。大字体下首页主视觉改为自然流布局。

## IP 与动效

内建 imagegen 生成欢迎挥手、专注电脑、拥星庆祝三种立体形态；头像由同一角色规范裁切。待审批、闲置与错误保留原 IP 的对应表情，避免用无关表情替代真实状态。

正式素材在 `app/assets/mascot-v2/`，9 张角色 PNG 共约 1.25 MB。旧素材保留在源码中，已从应用资产清单移除。位图承担角色和装饰，排版、文字、控件、背景与布局用 Flutter 原生绘制。

本机 Blender 制作香槟金星轨，透明 PNG 位于 `app/assets/motion/dream-orbit.png`，可编辑场景位于 `scripts/design/motion-star-orbit.blend`。运行时使用有限时的角色入场、状态切换和按压动效；正文增量更新不反复播放角色动作。尊重系统减少动画设置。

## 验证

- 35 项 Flutter 测试通过，覆盖模型设置确认、草稿保留、追加/停止、审批、只读权限、真实会话选择与历史分页。
- 新增 320px 窄屏配合 1.4 倍字体、320×568 手机配合 300px 键盘遮挡的交互回归检查。
- 4 项独立动效检查通过，覆盖有限动画结束、减少动画、销毁与原生点击。
- Flutter analyze 无问题，release Web 构建通过。
- 浏览器验收手机与 1280px 桌面布局、角色互动、项目/主机导航和真实模型目录。
- 素材通过 alpha 边界及奶白、深可可、棋盘三种底色检查。

新构建和测试输出均放在仓库外的临时 QA 工程；未使用 pnpm。后端协议未更改。
